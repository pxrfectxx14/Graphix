# Graphix

**[English](README.md)** | **[Русский](README.ru.md)**

#### **Настольное приложение для построения графиков функций и их математического анализа, написанное на Python (CustomTkinter + Matplotlib + SymPy).**
---


### Возможности

- Построение графиков одной или нескольких функций одновременно
- Приближение и панорамирование графика колёсиком мыши
- Область определения и область значений
- Точки пересечения с осями Ox и Oy
- Точки разрыва
- Производная и критические точки
- Минимумы и максимумы (с отметкой на графике)
- Промежутки знакопостоянства
- Поддержка неявного умножения (`2x`, `3sin(x)`, `x^2`)
---

### Требования

- Python 3.9+
- `customtkinter`, `matplotlib`, `numpy`, `sympy`
---

### Установка

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install customtkinter matplotlib numpy sympy
```
---

### Запуск

```bash
python main.py
```

Введите функцию (например, `x**2 - 4` или `sin(x)`) и нажмите «Построить график».
